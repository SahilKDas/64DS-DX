# Host character packs

Each directory contains a redistributable manifest. Imported third-party
geometry, textures, and voices are generated locally into the same directory
and are intentionally excluded until their authors grant redistribution terms.

The current logical roster is Mario 0, Luigi 1, Wario 2, Yoshi 3, Waluigi 4,
and Toad 5. `resourceCharacter` selects the retail DS body/gameplay baseline;
host geometry, materials, properties, and voices then override that baseline.
